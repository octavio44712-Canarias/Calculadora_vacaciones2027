Cuadrante de guardias de Frigorista

Toca un día laborable para marcarlo como vacaciones. Vuelve a tocarlo para quitarlo. Los festivos y fines de semana no consumen vacaciones. Las guardias se muestran con una franja roja para que no oculten otros colores. Los cambios se guardan en este dispositivo.
